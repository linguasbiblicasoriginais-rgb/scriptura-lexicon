# JASTROW — Avaliação de traduções

170 lotes de 100 verbetes. Cada arquivo contém a glosa publicada, a definição e as notas do XML original, os identificadores e as pendências explícitas. A ausência de indícios automáticos NÃO significa tradução aprovada.

Contagem inicial: 2.046 verbetes com inglês identificado por marcação, mais nove casos de inglês sem marcação identificados previamente. As avaliações linguísticas individuais permanecem pendentes. Nenhum módulo lexicográfico foi modificado.
