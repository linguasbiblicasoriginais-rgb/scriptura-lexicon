# Atribuição da transcrição grega — Perseus Digital Library

O texto grego adaptado de Antiguidades Judaicas nos cinco arquivos josefo/texts/ant-group-*.js provém de:

**Perseus Digital Library (Tufts University)**, edição de Benedikt Niese, *Flavii Iosephi opera* (1885–1890), arquivo tlg0526.tlg001.perseus-grc2.xml.

Fonte: https://github.com/PerseusDL/canonical-greekLit/blob/master/data/tlg0526/tlg001/tlg0526.tlg001.perseus-grc2.xml

SHA original: b7311f2559afeb84a9f95484d8d02d04a0bad86c.

Adaptação: estrutura TEI/XML convertida em objetos JavaScript; marcas XML e de paginação retiradas, espaçamento normalizado, texto associado aos livros, capítulos Whiston e seções Niese; interface de leitura adicionada. Nenhuma redação grega foi gerada livremente.

Esta atribuição não altera os termos de licença dos demais componentes independentes do projeto.
